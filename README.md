# Placement Guidance Portal

## About the Project
The Placement Guidance Portal is a web-based application designed to help students prepare for placements. It provides learning resources for Data Structures and Algorithms (DSA), company-wise interview questions, and aptitude preparation.

## Features
- **DSA Learning Mode:** Learn DSA topics and practice questions.
- **Company Mode:** Explore company-wise interview questions.
- **Aptitude Preparation:** Practice aptitude questions for placement exams.
- **Learning Resources:** Access study materials to support placement preparation.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## How to Run Locally
1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL in XAMPP.
4. Import the project database into phpMyAdmin.
5. Configure the database connection files with your local MySQL settings.
6. Open the project in your browser using `http://localhost/The%20project/` (adjust the path to match your folder name).

## Purpose
This project was developed to help students organize their placement preparation resources in one place.
